---

## 🌿 Overview

COCOMPIRE is a front-end web project built using **HTML**, **CSS**, and **JavaScript**.  
The website highlights the brand’s story, showcases premium coconut-based products, explains their uses, and features testimonials and contact options.  
It’s designed to be **clean, responsive, and user-friendly** across all screen sizes.

---

## ✨ Features

- 🖼️ **Hero Slideshow** – Rotating coconut oil imagery with smooth fade transitions.  
- 🏢 **About Section** – Describes the brand’s purity, sustainability, and mission.  
- 🛍️ **Product Showcase** – Grid-based product layout with prices and cart buttons.  
- ⚖️ **Oil Comparison Table** – Virgin vs. Regular oil benefits visualized.  
- 💆‍♀️ **Usage Guide** – Displays real-life applications: cooking, skincare, and haircare.  
- 💬 **Customer Testimonials** – Reviews from satisfied users.  
- ❓ **Interactive FAQ** – Expanding answers using JS toggle.  
- 📩 **Contact Form** – Includes success pop-up confirmation box.  
- 👣 **Responsive Footer** – With quick links, social icons, and brand info.

## 🚀 Getting Started

To run this project locally:

1. Clone the repository:
```bash
git clone https://github.com/Mohamed-Asif-1000/COCOMPIRE-Virgin-Coconut-Oil-Brand-Website.git
```

2. Navigate to the Project Folder:
```bash
cd COCOMPIRE-Virgin-Coconut-Oil-Brand-Website
```

3. Open index.html in your preferred web browser.

## 📌 Usage

- **View Products**      : Browse through our range of premium virgin coconut oil–based products.  
- **About Section**      : Learn about COCOMPIRE’s story, sustainability, and purity.  
- **Comparison Section** : Understand the difference between Virgin and Regular coconut oils.  
- **Usage Guide**        : Discover various ways to use coconut oil for cooking, skincare, and haircare.  
- **Testimonials**       : Read reviews from satisfied customers.  
- **FAQ Section**        : Expand and collapse questions for quick answers.
